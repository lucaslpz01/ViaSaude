# Via Saúde

Site institucional de apoio à saúde pública para mostrar disponibilidade, fila estimada, distância, lotação e agendamento de consultas e exames.

## Onde trocar por imagens reais

Os placeholders do hero e do fundo ficam em:

- `frontend/images/hero-1.webp`
- `frontend/images/hero-2.webp`
- `frontend/images/hero-3.webp`
- `frontend/images/hero-4.webp`
- `frontend/images/health-bg.webp`

Para substituir por fotos reais, use bancos gratuitos com licença que permita uso em sites, por exemplo:

- Unsplash: https://unsplash.com/
- Pexels: https://www.pexels.com/
- Pixabay: https://pixabay.com/

Dica: prefira imagens com licença livre para uso comercial e sem necessidade de atribuição, e mantenha o mesmo nome dos arquivos para facilitar troca rápida.

## Observações importantes

- O site é pensado para rede pública.
- O portal não decide prioridade de atendimento e não substitui a classificação de risco da equipe de saúde.
- Dados de demonstração estão em `frontend/js/data.js` e podem ser trocados por dados reais depois.
- Conteúdo e identidade visual foram criados para o Via Saúde e não copiam marcas ou identidades de outras instituições.
